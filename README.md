# nassauTickets

Sistema de Controle de Atendimento para um Laboratório de Análises Clínicas.

## Objetivo
Consolidar conhecimentos de desenvolvimento Web, organização de projetos, Git/GitHub, documentação e React[cite: 1].

## Tecnologias Utilizadas
- **Frontend:** React 19 (via Vite)[cite: 6].
- **Backend (Planejado):** Node.js LTS 22[cite: 6].
- **Banco de Dados (Planejado):** MySQL 8.0[cite: 6].

## Instruções de Instalação e Execução (Frontend)

Para executar o painel e o totem interativo:

1. Certifique-se de ter o Node.js instalado.
2. Navegue até a pasta do frontend:
3. cd frontend
4. npm install
5. npm run dev
6. Acesse o endereço local fornecido no terminal
